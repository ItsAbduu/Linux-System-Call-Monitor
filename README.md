# Linux System Call Monitor

A lightweight, behavior-based monitoring tool for analyzing Linux system calls and detecting anomalous process behavior.

> **Status:** 🚧 Work in Progress - Bachelor Graduation Project

## Overview

This project aims to explore system-level security by analyzing system calls generated by running processes.
Instead of relying on known signatures, it focuses on behavioral patterns to identify potentially malicious behavior.

The system builds simple behavioral profiles of processes and detects deviations from normal execution patterns.

**Key Idea**

Modern malware often evades signature-based detection.
This project adopts a behavior-based approach, where:

- Each process is characterized by its system call behavior
- Normal behavior is learned through baseline profiling
- Suspicious behavior is detected as deviations from expected patterns

## Features

- ✅ Real-time system call monitoring (via "ptrace")
- ✅ Per-process syscall tracking (PID-based)
- ✅ Frequency-based analysis of system calls
- ✅ Sequence pattern observation
- ✅ Baseline behavior profiling
- ✅ Simple anomaly detection engine

## Planned

## Example Detection Scenario

A normal process may follow predictable patterns:

- "open → read → write → close"

Whereas a suspicious process might show:

- Unusual frequency of "execve"
- Unexpected use of "ptrace"
- Abnormal syscall sequences or spikes

The system flags such deviations for further analysis.

## Objectives

1. Understand low-level system behavior through system calls
2. Explore intrusion detection techniques based on process behavior
3. Build a lightweight and explainable monitoring tool
4. Gain hands-on experience in Linux system programming

## Methodology

- Capture system calls in real time using "ptrace"
- Log behavior per process (PID-based tracking)
- Build baseline profiles for normal behavior
- Apply rule-based and statistical analysis to detect anomalies
